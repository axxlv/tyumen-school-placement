**Методическое отклонение от практики 2:** исторический пешеходный граф построен из локального PBF OpenStreetMap, тогда как преподаватель просит выбрать и скачать готовый граф. Это следует явно указать в материалах и видео. Без согласования с преподавателем нельзя назвать этот пункт полностью выполненным. В рамках финальной подготовки матрица, граф, территория и результаты не заменяются ради формального совпадения.

## Что должно попасть в передаваемый комплект

- Код приложения, `web/`, инструкции запуска и зависимости.
- Ноутбук полного поиска и его клиент; сохранённый выполненный ноутбук прошлой практики, генератор дашборда и готовый HTML.
- Обновлённые входные данные прошлой практики, школьный CSV, GeoJSON, параметры и сведения об оценочном характере величин.
- Завершённая база `state/application.sqlite` либо её корректная SQLite-резервная копия, чтобы преподаватель увидел сохранённые А/Б/В и историю поиска в браузере без нового перебора. Обычный `.gitignore` приложения исключает `.sqlite`: отдельно проверить включение базы в архив данных.
- Матрица `accessibility_matrix.parquet` и другие крупные необходимые файлы. Матрица занимает 332 783 645 байт и не подходит для обычной загрузки в GitHub: передать отдельным архивом и дать рабочую ссылку.
- Полный рейтинг и все равноценные лучшие, итоговое сравнение, карты, отчёты проверок.
- Понятное описание структуры папок и размещения отдельно переданных данных. Для воспроизведения ремонта населения нужен исторический вход `previous_population_version/buildings.geojson`; для просмотра итогов и повторных сценариев он не требуется.

Не включать окружения `.venv*`, токены и `.env`, кэш, `.backups`, ненужные старые прогоны и другие города. Не удалять их из рабочей папки ради подготовки архива. Установка на другом компьютере требует согласованного окружения; другая версия библиотек или CBC может сделать сохранённые результаты несовместимыми для продолжения, хотя CSV и HTML останутся доступны для просмотра.

## Что остаётся сделать самостоятельно

1. **Сохранить ноутбуки с результатами.** Открытые несохранённые выводы VS Code не попадут в передаваемые `.ipynb` автоматически.
2. **Записать видеоотчёт** по `VIDEO_GUIDE.md`: обновлённая практика 2 → исходные данные → А/Б → завершённый поиск → В → сравнение и ограничения. Рекомендация 7–10 минут не является требованием преподавателя. Не запускать новый полный поиск во время записи.
3. **Опубликовать подготовленные файлы** в своём репозитории самостоятельно. Проверить репозиторий в браузере: локальные изменения не появляются на GitHub автоматически. При закрытом репозитории обеспечить преподавателю доступ.
4. **Разместить отдельный архив крупных данных** в выбранном хранилище и добавить его реальную ссылку и инструкцию распаковки в README. Ссылка на хранилище не создана этой проверкой; выдуманной ссылки здесь нет.
5. **Проверить доступ к передаваемым материалам**: ссылка на репозиторий, архив данных и видео открываются с учётом нужных прав. Убедиться, что адрес `127.0.0.1` — только локальный способ просмотра, а не публичная ссылка преподавателю.
6. **Самостоятельно отправить преподавателю** ссылку на репозиторий, данные и видео предусмотренным им способом. Ни публикация, ни отправка этой проверкой не выполняются.

Перед отправкой обязательно озвучить/зафиксировать отклонение с источником пешеходного графа и ограничения оценок населения и школьной вместимости. Готовое приложение не подтверждает возможность строительства школы на конкретном земельном участке.
