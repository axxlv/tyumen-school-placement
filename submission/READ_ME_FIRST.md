# Готовые материалы: Тюмень, практики 2 и 3

1. **Посмотреть прошлую практику:** откройте `python-package-boilerplate-updated/examples/data_tyumen/dashboard_refined.html` в браузере. Для внешних библиотек карты может требоваться интернет. Сам HTML содержит сохранённые геоданные и графики.
2. **Открыть новое приложение:** на исходном компьютере выполните в PowerShell из корня комплекта:

   ```powershell
   powershell -ExecutionPolicy Bypass -File ".\OPEN_PROJECT.ps1" -Port 8767
   ```

   Откройте http://127.0.0.1:8767/ и http://127.0.0.1:8767/practice2. Если сервер уже запущен с этой базой, используйте существующую вкладку — вторую копию не запускайте. Эта команда загружает модель, но не запускает полный перебор.
3. **На другом компьютере:** распакуйте полный архив с двумя папками проектов. Нужен Python 3.12 с пакетами из `requirements-lock.txt`; командой `OPEN_PROJECT.ps1 -Python "C:\путь\Scripts\python.exe"` можно указать созданную среду. Среда Python в комплект не копируется. Создание среды и скачивание пакетов требуют отдельной установки; чистая установка на другом ПК не проверялась. Важны точные версии NumPy/Pandas/PuLP/BlocksNet и бинарник CBC. При иной подписи старые сценарии остаются архивными; таблицы, карты, отчёт и статический HTML всегда можно просмотреть без нового поиска.
4. **Где результаты:** `school-placement/state/experiment-results/EXPERIMENT_REPORT.md` и соседние CSV/PNG. В базе уже есть А/Б/В и завершённый поиск 12 805/12 805, ошибок 0. Не запускайте «Разместить автоматически» заново для видео.
5. **Где пояснения:** VIDEO_GUIDE.md — последовательность показа; REQUIREMENTS_REVIEW.md — требования и оговорки; SUBMISSION_CHECKLIST.md — что осталось сделать пользователю.

## Публикация

`PROJECT_FOR_GITHUB.zip` нужно распаковать и перенести его содержимое в собственный репозиторий: две папки проектов, документы и launcher. Это комплект файлов, не уже выполненный git push. Исходная прежняя работа на компьютере сохранена отдельно.

`COMPLETE_PROJECT_WITH_DATA.zip` содержит также матрицу и согласованную SQLite-копию результатов. Архив велик: загрузите его в доступное преподавателю хранилище, затем **самостоятельно добавьте настоящую ссылку** в README GitHub. Ссылка на хранилище не создавалась и не выдумывалась. Сохраните структуру директорий при распаковке. `MANIFEST.json` перечисляет файлы и SHA-256.

Не добавляйте в GitHub `.venv`, `.env`, кэш, `.backups` и временные журналы. Архивы подготовлены без этих файлов. В комплекте для GitHub нет матрицы 332 783 645 байт и SQLite-базы: они находятся в полном архиве.

## Главное ограничение

Требование практики 2 про скачанный готовый граф не выполнено буквально: в исторической работе использован пешеходный граф, собранный по локальному OSM. В итоговых материалах это явно отмечено. Модель населения и вместимости оценочная; выбор участка строительства не выполнялся. Замена графа и пересчёт эксперимента сейчас не производились.
