## Границы проверки

Проверена согласованность принятых данных, расчёта и вывода. Не выполнялась новая проверка достоверности каждой школьной оценки по внешним источникам; CSV принят как подготовленный пользователем основной набор. Не доказываются фактическая численность жителей, проектные мощности всех школ и пригодность участка для строительства. Изучены все основные разделы и 40 переключений карты; не утверждается проверка каждой возможной пары интерактивных состояний. Запуск с чистой установкой на ином компьютере/ОС не выполнялся.

## Материалы и оставшиеся действия

Полный локальный комплект содержит две папки проектов, SQL-базу, матрицу и документацию. Для GitHub подготовлен отдельный комплект исходников/отчётов без крупной матрицы и базы; их нужно передать отдельно с сохранением структуры. Архивы не размещались в интернете. `127.0.0.1` — локальный адрес, преподаватель не сможет открыть его на вашем компьютере.

Пользователю остаётся: сохранить открытые ноутбуки (Ctrl+S, не запускать снова поиск), опубликовать подготовленные файлы и загрузить полный архив в доступное преподавателю хранилище, добавить фактическую ссылку на архив в README репозитория, записать видео по VIDEO_GUIDE.md, самостоятельно отправить ссылки и работу. Новых долгих расчётов не требуется.


При итоговой визуальной проверке исправлены два общих дефекта дашборда: цвет неизвестного населения согласован с легендой и описанием, а логарифмические гистограммы переведены на log10(1+x), соответствующий подписям 10^tick−1 (ранее использовался натуральный log1p при десятичных подписях). Медиана приведена к той же шкале. Это исправления визуализации сохранённых значений, без изменения самих метрик.
