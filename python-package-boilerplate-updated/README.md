## Ноутбук и видеоотчёт

Основной `examples/tyumen_pipeline_refined.ipynb` — выполненный обзор текущих сохранённых этапов с результатами, картами и таблицей соответствия примеру BlocksNet. По умолчанию он только читает готовые файлы: без скачивания и нового расчёта модели. Предыдущая школьная надстройка сохранена как `tyumen_school_update_previous.ipynb`; полный исторический пайплайн — `tyumen_pipeline_refined_previous.ipynb`. Исторические файлы используют старые правила и не должны запускаться поверх актуальной базы.

Точная методическая оговорка: граф пешеходный, был собран в предыдущем этапе из локального OSM/PBF. Требование задания 2 о скачанном готовом графе не выполнено буквально; эта разница не скрывается и не исправляется заменой матрицы после эксперимента. Интермодальный граф не используется.

Актуальные итоги и инструкция показа двух работ: ../submission/VIDEO_GUIDE.md; сверка требований: ../submission/REQUIREMENTS_REVIEW.md. POPULATION_REPAIR_REPORT.md и UPDATE_REPORT.md — отчёты соответствующих исторических этапов, их прежние списки дальнейших действий не являются текущим статусом.
